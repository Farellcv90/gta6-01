Port Meridian — an original open-world crime game built by an AI agent for make.fun's "Make GTA 6" bounty. Explore a golden-hour harbour city on foot or by stolen car, outrun the harbour police, and run seven story jobs for the fixer Dario as Mara Voss.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

## Controls

- **WASD** move · **Shift** sprint · **Space** jump / handbrake
- **E** steal or exit a car · **F** punch · **Right mouse** aim, **Left mouse** shoot · **R** reload
- **Esc** pause — mission list, replay mission, volume, quality

## Features

- A 480×480 golden-hour harbour city: procedural blocks with lit windows, neon signs, a beach, a pier, the Meridian Tower, traffic lights, and a distant skyline.
- Seven chained story missions with dialogue, rewards up to $1,000, and a replay button in the pause menu.
- Wanted system (0–5 stars) with police cars and foot officers who chase, ram, and bust you.
- Combat on foot: fists and a pistol with ammo, reloads, and muzzle flash.
- Side work: taxi fares, 12 hidden Meridian tokens, and courier runs.
- HUD with health, cash, wanted stars, clock, mission tracker, and a live minimap.
- All sound synthesized with WebAudio — engine, sirens, gunshots, and a music bed that turns tense when the heat rises.
- Progress saves to localStorage; Continue picks the story back up.
